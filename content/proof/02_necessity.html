Proposition (necessity). If $V$ is a finite set of cells with $K(x+i,d+j)\ne0$ at every $(i,j)\in V$ for some base point $(x,d)$, then $V$ is admissible. In particular, if a shape $S$ is packed into some $(x,d)$, then its cells of region type $\pm1$ form an admissible set.

Proof. Suppose $V$ hits every class modulo some prime $p$. Then in particular some $(i,j)\in V$ satisfies $(i,j)\equiv(-x,-d)\pmod p$. So $p$ divides both $x+i$ and $d+j$, and their greatest common divisor is not $1$: it is a multiple of $p$, or $0$ when both numbers are $0$. By Fact 2, $K(x+i,d+j)=0$, a contradiction. $\blacksquare$

This is the "only if" half of Theorem 1, and also of Corollary 2: the cells of a region of type $\pm1$ have region type $\pm1$, so the region is admissible, and no neighbour of a region of type $0$ has region type $0$ (it would belong to the region), so the neighbour set of such a region is admissible.
